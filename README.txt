Telegram-бот для подписок на av.by

ЗАПУСК
Требуется Node.js 22.18+ (ветка 22). Бот использует встроенные fetch и
node:sqlite; npm install для запуска бота не нужен. SQLite в Node 22
показывает предупреждение об экспериментальном API.

1. Создайте бота через @BotFather → /newbot.
2. Скопируйте .env.example в .env и задайте TELEGRAM_BOT_TOKEN.
3. При необходимости заполните TELEGRAM_ALLOWED_USER_ID для доступа только
   своего пользователя. Без него бот доступен всем в личных чатах.
4. npm run bot
5. Откройте бота в Telegram: /start.

Токены храните локально. Работать должен один процесс на токен и базу.
Остановка: Ctrl+C; дождитесь завершения текущего запроса/обхода.

ПОДПИСКИ
/new — создать; /subscriptions — список; /cancel — отменить настройку.
Выбор: марка → модель → поколение → валюта → максимальная цена → год от/до
→ максимальный пробег → подтверждение. Поколение и числовые фильтры можно
пропустить. Доступны «Назад», пауза, возобновление, удаление.
Для изменения условий создайте новую подписку и удалите старую.
Лимит — 10 подписок на чат. Интервал задаёт POLL_INTERVAL_SECONDS (по умолчанию 300).

Первый успешный полный обход сохраняет текущие совпадения без уведомлений.
Затем бот сообщает о впервые найденных совпадениях. Изменение цены старого
объявления тоже может впервые привести его в выборку. Поднятие знакомого ID
не вызывает уведомления. После паузы могут прийти находки за время паузы.
Уведомления текстовые, со ссылкой; отдельные фото пока не отправляются.

База и черновики: data/bot.sqlite. Очередь уведомлений сохраняется при сбое.
При аварии между отправкой в Telegram и записью результата возможен повтор.
Источник — внутренний JSON HTML-страницы av.by, а не стабильный официальный API.
Цена, год и пробег фильтруются локально после загрузки категории.

ПРОВЕРКИ И ИНСТРУМЕНТЫ
npm test
npm run search:av -- --filters examples/audi-filter.json
npm run catalog:av -- --brand 8
npm run catalog:av -- --brand 6 --model 5810

Команды поиска и справочников сохраняют результаты в artifacts/.
Эта папка создаётся автоматически и не требуется для работы бота или тестов.
Тесты используют компактный образец в tests/fixtures/av-page.json.
На проверенном запуске Audi A4: 4 страницы, 76 уникальных объявлений,
11 совпадений с examples/audi-filter.json. Эти цифры не актуальная выдача.

CLOUDFLARE: ЭКСПЕРИМЕНТАЛЬНАЯ ПРОВЕРКА
cloudflare/probe — отдельный тестовый Worker. Telegram-бот ещё не перенесён
на Cloudflare: нет webhook, D1 или расписания мониторинга в облаке.
Worker проверяет загрузку и разбор одной страницы av.by за вызов.

npm run cf:install
npm run cf:login
npm run cf:build
npm run cf:deploy
npm run cf:probe -- https://avby-source-probe.ВАШ-ПОДДОМЕН.workers.dev

cf:install восстанавливает Wrangler по package-lock.json (npm ci).
cf:login открывает браузер для входа в Cloudflare. После deploy подставьте
выданный URL вместо примера. Для теста используйте Workers Free.
cf:deploy создаёт cloudflare/probe/.probe-secret.json, если его ещё нет,
и публикует этот отдельный ключ как Worker Secret. Токен Telegram не нужен.
cf:probe читает ключ автоматически и сохраняет отчёт в artifacts/cloudflare-*/.
Запускается 6 последовательных запросов: первая страница трижды и страницы 2–4.

CPU проверяйте в Cloudflare → Worker → Metrics → CPU Time per execution
и Observability/Logs. Обычные JS-таймеры не измеряют CPU опубликованного Worker.
В отчёте cpuMs=null намеренно. Успешные локальные тесты и HTTP 200 не доказывают
соответствие лимиту Free (10 мс CPU на вызов). Для решения о переносе нужны
измерения нескольких вызовов с запасом на БД, диалог и отправку сообщений.
При 403/429/капче проверьте доступность источника; при 1102/exceededCpu
потребуется оптимизация. Измерения CPU в облаке пока не подтверждены.

Документация:
https://developers.cloudflare.com/workers/platform/limits/
https://developers.cloudflare.com/workers/observability/metrics-and-analytics/
https://developers.cloudflare.com/workers/runtime-apis/performance/

ПЕРЕНОС НА ДРУГУЮ МАШИНУ
Остановите бота и дождитесь выхода. Перенесите проект вместе с .env, всей
папкой data/ и cloudflare/probe/.probe-secret.json, если файл существует.
Они исключены из Git — одного клонирования недостаточно.
node_modules, dist, .wrangler, artifacts и настройки .idea переносить не нужно.
На новой машине: npm test, затем npm run bot.
Для Cloudflare дополнительно: npm run cf:install и npm run cf:login.
